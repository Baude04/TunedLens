# TunedLens

Reimplementation of TunedLens from the article "Eliciting Latent Predictions from Transformers with the Tuned Lens" on HuggingFace's SmolLM2-1.7B. TunedLens are trained on a very small subset of ```fineweb-edu```, using muon optimizer, as recommended in the original paper. 

See ```notebooks/notebook.ipynb``` for of usage examples.
